# n1: calm day

Zone: all zones
Layers involved: Twin, Guardian, Brain

## Trigger

* From the page: open the Scenario Control page of the Twin (port 8080) and click the card "Calm day".
* From the command line, at the root of the repository: `python scenarios/n1.py`.

Each run writes one log file in `logs/`, named `n1-<date>-<time>.log`.

## What the Twin does

Nothing unusual. Traffic stays under 50%, the building stays at about 22 C with no smoke, and the bins fill slowly and empty themselves at 70%. For 60 s the city status stays NORMAL.

## What the other layers should do

The Guardian marks every sensor TRUSTED. The Brain must not overreact: it writes no command on any actuator.

## Pass criteria

* The log has no ALERT line and no COMMAND line.
* The city status stays NORMAL.
