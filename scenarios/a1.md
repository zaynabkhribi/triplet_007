# a1: traffic jam

Zone: A (traffic)
Layers involved: Twin, Brain

## Trigger

One trigger starts the scenario. Either of these does the same thing:

* From the page: open the Scenario Control page of the Twin (port 8080) and click the card "Traffic jam".
* From the command line, at the root of the repository: `python scenarios/a1.py` (it runs `python src/twin.py run a1` in the `twin/` folder).

Each run writes one log file in `logs/`, named `a1-<date>-<time>.log`. On the page, the button "Reset all" returns every sensor to normal.

## What the Twin does

* +5 s: roads 1 and 2 start to jam (`us-a-traf-01`, `us-a-traf-02`).
* +10 s: congestion is about 50%, the operations centre raises a WARNING.
* +25 s and +30 s: congestion passes 75%, the alert becomes CRITICAL.
* If nothing answers, the jam stays. It does not end by itself.
* When the light and the sign are commanded, the congestion drops and both alerts clear about 10 s later (+45 s in the timed run).

## What the other layers should do

The Brain reads the congestion. At 75% or more it writes `phase=green` and `mode=manual` on `us-a-light-01`, and a message on `us-a-sign-01`. In the timed run (`run a1`) the Twin plays this answer itself at +35 s.

## Pass criteria

* Log has ALERT RAISED then ALERT ESCALATED for TRAFFIC_JAM.
* Log has a COMMAND line for the light and one for the sign.
* Log has ALERT CLEARED for both roads and the city status goes back to NORMAL.
