# d1: Brain down, the fire keeps burning

Zone: B (building)
Layers involved: Twin (the Brain is absent)

## Trigger

* From the page: open the Scenario Control page of the Twin (port 8080), untick "Mock Brain acts automatically" and click the card "Brain down, the fire keeps burning".
* From the command line, at the root of the repository: `python scenarios/d1.py`.

Each run writes one log file in `logs/`, named `d1-<date>-<time>.log`.

## What the Twin does

* +5 s: the building starts to burn.
* The alert goes WARNING, then CRITICAL.
* Nobody writes the alarm or the dispatch, so the fire does not stop. The Twin keeps publishing every device on every tick.

## What the other layers should do

The Guardian marks the building TRUSTED. The Brain is down, so it writes nothing. The test shows that one missing layer does not stop the city.

## Pass criteria

* The log has no COMMAND line.
* The fire alert stays CRITICAL until the end of the log.
* The log has PUBLISH lines for every device up to the last tick.
