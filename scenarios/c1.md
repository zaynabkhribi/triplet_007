# c1: waste and illegal dumping

Zone: C (collection point)
Layers involved: Twin, Brain

## Trigger

One trigger starts the scenario. Either of these does the same thing:

* From the page: open the Scenario Control page of the Twin (port 8080) and click the card "Waste / illegal dumping".
* From the command line, at the root of the repository: `python scenarios/c1.py` (it runs `python src/twin.py run c1` in the `twin/` folder).

Each run writes one log file in `logs/`, named `c1-<date>-<time>.log`. On the page, the button "Reset all" returns every sensor to normal.

## What the Twin does

* +5 s: the camera `us-c-cam-01` detects dumping and `us-c-bin-01` fills fast. The dumping alert is raised at once.
* +25 s: the bin passes 80%, WARNING.
* +30 s: the bin passes 95%, CRITICAL.
* The incident stays until a cleaning task exists.
* +50 s: 10 s after the task, the cleaning is done, the dumping is cleared and the bins are emptied.

## What the other layers should do

The Brain writes `taskStatus=created` and a `location` on `us-c-task-01`. In the timed run the Twin plays this answer at +40 s.

## Pass criteria

* Log has ALERT RAISED for ILLEGAL_DUMPING and for BIN_FULL.
* Log has a COMMAND line for the task and the EFFECT line "cleaning done".
* Both alerts are CLEARED.
