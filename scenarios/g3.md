# g3: fake traffic jam

Zone: A (traffic)
Layers involved: Twin, Guardian, Brain

## Trigger

One trigger starts the scenario. Either of these does the same thing:

* From the page: open the Scenario Control page of the Twin (port 8080) and click the card "Fake traffic jam".
* From the command line, at the root of the repository: `python scenarios/g3.py` (it runs `python src/twin.py run g3` in the `twin/` folder).

Each run writes one log file in `logs/`, named `g3-<date>-<time>.log`. On the page, the button "Reset all" returns every sensor to normal.

## What the Twin does

* +5 s: `us-a-traf-03` reports the same high congestion on every tick while its road is free. The operations centre only shows raw values, so it raises a TRAFFIC_JAM alert at once (91% in the test run). Judging it is the job of the Guardian.

## What the other layers should do

The Guardian marks `us-a-traf-03` UNTRUSTED. The Brain must not change a light or a sign because of it.

## Pass criteria

* Log has MODE fake_jam for `us-a-traf-03`.
* No COMMAND line for the lights or the sign.
* Guardian verdict for `us-a-traf-03` is UNTRUSTED.
