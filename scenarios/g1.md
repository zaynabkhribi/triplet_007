# g1: spoofed smoke reading

Zone: B (building)
Layers involved: Twin, Guardian, Brain

## Trigger

One trigger starts the scenario. Either of these does the same thing:

* From the page: open the Scenario Control page of the Twin (port 8080) and click the card "Spoofed smoke reading".
* From the command line, at the root of the repository: `python scenarios/g1.py` (it runs `python src/twin.py run g1` in the `twin/` folder).

Each run writes one log file in `logs/`, named `g1-<date>-<time>.log`. On the page, the button "Reset all" returns every sensor to normal.

## What the Twin does

* +5 s: `us-b-bldg-01` reports 400 ppm of smoke while the temperature stays at 22 C. A real fire would raise both.
* The operations centre only shows the raw reading, so it raises a FIRE alert. Judging it is the job of the Guardian.
* Nothing burns. The scenario ends after 40 s of log.

## What the other layers should do

The Guardian marks the sensor UNTRUSTED (smoke without heat). The Brain must not sound the alarm and must not dispatch units.

## Pass criteria

* Log has MODE spoof_smoke for `us-b-bldg-01`.
* Log has no COMMAND line for `us-b-alarm-01` or `us-b-disp-01`.
* Guardian verdict for `us-b-bldg-01` is UNTRUSTED.
